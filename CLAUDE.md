# Repository guide for Claude

This repository holds two things:

- **The profile site** (`index.html`, `404.html`) served by GitHub Pages from `main`.
  Keep it dependency-free static HTML.
- **Qimma** (`qimma/`), an Expo app for web, Android and iOS that trains learners for English
  exams (PTE Academic and PTE Core first). For any Qimma work, read `qimma/HANDOFF.md` first,
  or run `/continue-qimma`.

The agent team (`.claude/agents/`) and the project skills (`.claude/skills/`) live here at
the root, so start Claude Code from the repository root.
